프로젝트 개요

(주)인사이트넥서스연구원은 교육 서비스를 제공하는 기업으로, 효율적이고 안정적인 웹 플랫폼이 필요했습니다. 복잡한 서버 관리 없이 콘텐츠 업데이트가 용이하고, 보안성과 성능을 동시에 확보할 수 있는 솔루션을 요구했습니다.

이 프로젝트는 GitHub Pages 기반의 정적 사이트 생성과 Notion을 활용한 콘텐츠 관리 시스템을 통해 교육 기관에 최적화된 웹 플랫폼을 구축하는 것을 목표로 했습니다.

기술 스택 및 아키텍처

호스팅 환경

GitHub Pages를 통한 무료 호스팅으로 99% 정적 사이트를 구축했습니다. 별도의 웹 서버나 복잡한 백엔드(DB, PHP/Python/Node.js 등) 없이 HTML, CSS, JavaScript 파일만으로 구성되어 높은 안정성을 확보했습니다.

프론트엔드 기술

반응형 디자인을 위한 Custom CSS Framework와 JavaScript를 사용했으며, 각 메뉴 클릭 시 새로운 HTML 파일을 로드하는 멀티 페이지 아키텍처(MPA) 방식을 적용했습니다.

콘텐츠 관리 시스템

Notion 연동을 통해 뉴스/게시판 관리를 구현했습니다. 운영진은 복잡한 서버 관리 없이 Notion만으로 게시물 작성 및 관리가 가능하며, 웹사이트 업데이트 없이도 콘텐츠를 즉시 반영할 수 있습니다.

  • • 최적화된 정적 파일 제공

  • • 서버 운영비 없음
  • • 유지보수 비용 최소화

⚡ 관리 편의성

  • • Notion을 통한 콘텐츠 관리
  • • 개발자 없이도 업데이트 가능
  • • 직관적인 관리 인터페이스

개발 프로세스

1단계: 요구사항 분석
교육 기관의 특성을 고려한 기능 요구사항 분석 및 기술 스택 결정

2단계: 정적 사이트 설계
멀티 페이지 아키텍처 설계 및 반응형 레이아웃 구성

3단계: Notion 연동 구현
뉴스 섹션과 Notion 페이지 연결 및 동적 콘텐츠 관리 시스템 구축

4단계: GitHub Pages 배포
자동 배포 파이프라인 설정 및 성능 최적화

기술적 성과

외부 서비스 연동 최적화

정적 사이트의 한계를 극복하기 위한 Notion API 연동으로 동적인 콘텐츠 관리가 가능한 하이브리드 시스템을 구축했습니다.

확장 가능한 아키텍처

향후 Google Forms, 외부 폼 서비스 연동을 통한 입학 신청 시스템 확장이 용이한 구조로 설계했습니다.

결과 및 성과

웹사이트 런칭 후 (주)인사이트넥서스연구원의 온라인 교육 플랫폼이 안정적이고 효율적으로 운영되고 있습니다. Notion을 통한 콘텐츠 관리로 운영진의 업무 효율성이 크게 향상되었으며, 서버 관리 부담 없이 지속적인 서비스 제공이 가능해졌습니다.

특히 GitHub Pages의 높은 가용성과 빠른 로딩 속도로 사용자 만족도가 향상되었으며, 무료 호스팅을 통한 운영비 절감 효과도 달성했습니다.
